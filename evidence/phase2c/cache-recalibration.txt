============================================================================
SCOPE LIMIT - READ BEFORE TRUSTING THE NUMBER
============================================================================
This is NOT the production embedder. `text-embedding-004` needs an API key, and CI runs in
replay with no key and no spend, so the vectors here come from the local hashed
bag-of-words + character-trigram embedder.

It is dimension-matched to production (768, D-043) and it exercises the whole path -- the
harness, the two-sided method, the false-hit accounting, the recommendation rule. What it
CANNOT establish is the number: a lexical embedder scores paraphrases that share words,
and a semantic one scores paraphrases that share meaning. Those disagree precisely on the
cases a threshold has to separate.

So this measurement closes the METHOD half of the gate item and leaves the NUMBER half
open. The number must be re-measured against text-embedding-004 on a real corpus, using
this same harness, before it is trusted -- and AAKAR_CACHE_THRESHOLD exists so that lands
as config rather than a code change.
