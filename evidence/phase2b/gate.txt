4. DEGRADED MODE  (2B.11)  - causes distinguished, per D-035
==========================================================================
  healthy:
     upload=True  generate=True  cached=True
     banner: (none)
  budget exhausted:
     upload=True  generate=False cached=True
     banner: New answers are paused because today's usage limit has been reached. Your library and all previously answered questions still work.
  provider unreachable:
     upload=True  generate=False cached=True
     banner: New answers are temporarily unavailable while the language model is unreachable. Your library and all previously answered questions still work.
  worker stalled:
     upload=False generate=True  cached=True
     banner: New uploads are paused because documents are not being processed right now. Everything already in your library still works, including questions.

  Note the difference: a stalled worker stops UPLOADS while questions keep working.
  A merged 'unavailable' state would have told the student otherwise.
